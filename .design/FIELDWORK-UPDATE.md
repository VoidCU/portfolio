# Fieldwork revision

The story is now an editorial sequence: Notice, Make, Release. Large verbs, compact writing and framed photographs replace the full-screen slideshow. Desktop records stack during scrolling; mobile and reduced-motion layouts read in normal document order. The hero and origin portraits remain intact.

The 3D universe and its lazy loader were removed. SignalDesk is a responsive typographic routing diagram with six disciplines, actual tool selections, keyboard tabs, contextual links, scroll progression and a manual override. It requires no WebGL. All ambient light effects and the light switch have been removed.

Ten photographic replacements cover the Himalayan origin, Kathmandu workspace, city valley, mountain panorama and PC setup in both day and night. They were generated with the built-in image_gen tool and saved to `public/assets/art/`. Exact prompts, generation sources and saved paths: [REALISM-PROMPTS.json](REALISM-PROMPTS.json). They are generated editorial illustrations, not documentary photos of Saroj's actual workspace. The existing profile photographs are unchanged.

The concealed interaction sequence now includes a 25-cell logic grid, a directed route-cost challenge, coupled phase dials and a keyed cipher. It remains unadvertised in the portfolio interface. Progress is local, using a new versioned key so the earlier sequence's save is preserved. Tests exercise solvability, progression, focus restoration and persistence without exposing a solution in the portfolio.

Verification: production build and lint; browser checks for the story, keyboard-operated skills, theme persistence, no WebGL or ambient controls, all existing pages, mobile overflow, and the complete concealed sequence. Screenshots are in `.design/qa/` (ignored).
